# CPU C4 filter implementation plan

Goal: implement and test the CPU projection of C4, then close revision issue 2.
Architecture: each critical request retains its originating non-cloud node as the local capability anchor. All placement paths require that node's advertised total CPU to cover the request. This is a capability test, not a spare-capacity reservation, local-only routing rule, or recovery protocol. Unknown anchors and unsupported GPU requests fail closed. Ordinary requests retain existing behavior.
Tech stack: native Tide Go runtime, protobuf events, Go tests, LaTeX.
