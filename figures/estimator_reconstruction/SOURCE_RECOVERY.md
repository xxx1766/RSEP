# Source recovery and interpretation

The two theses directly support reported historical summaries, and the restored main-text figures use those sources. This is separate from recovery of executable original experimental code.

Searches covered the complete accessible local Tide Git history (including the initial imported source), the associated tide-test checkout, the2026 TMC local archives and the archive named `Tide 闫文凯- TMC.zip`. That archive contains115 manuscript/figure members and no Go/Python/YAML experimental program. Accessible GitHub repository/history searches did not locate a corresponding original sliding-window or distributed YOLOX program. The user confirmed on2026-10-20 that no additional code repository/directory is available.

The old imported Tide path reads static estimates; the native33-run snapshot retains that behavior. The newly implemented estimator is explicitly a reconstruction: arithmetic20-completion windows initialized with independent per-node calibration, per-request admission-cost accounting, and sequenced100-ms feedback. Fixed controls use the same observation/feedback path. The author's particular window size, timing boundary, synchronization/probing choices and original distributed function are not claimed recovered.

The original single-host ablation explicitly performed ten detections per request. The distributed thesis descriptions identify YOLOX without establishing that repetition count, model variant or an integrated YOLOX/FaceNet request graph. The new experiment therefore contrasts one and ten real YOLOX-Nano inferences under a declared current protocol; neither is relabeled as the known original workload.

CPU budgets, topology and network differ as well: the new experiment uses a single ingress and three16-vCPU KVM hosts with12 application vCPUs each, an unshaped LAN and a finite cloud budget. The source heterogeneous study had three clients, three edges, a larger cloud and shaped cloud access. No inference from these new Tide-only runs is used to erase the old reported KubeEdge/Ray results or manufacture a new comparative ratio.

Four functional preflights validated500 successful requests,2750 actual forward passes and all500 execution-window samples. Their outputs are retained separately from formal measurements. The one/ten independent calibrations contain495 additional forwards.
